# Модули для Pill

Здесь лежит список модулей, который Pill показывает в магазине: «Управление → Модули → Доступные модули».
Модуль из этого списка любой пользователь Pill ставит одной кнопкой.

Модуль — это обычная программа для Windows. Писать её можно на чём угодно: C#, Python, C++.
Pill её скачивает, запускает, выключает и показывает её настройки.

---

## Как добавить свой модуль — по шагам

### Шаг 1. Сделайте программу

Программа — один `.exe` (рядом могут лежать другие нужные ей файлы).

Желательно, чтобы она умела закрываться сама, если её запустить с командой `--exit`.
Если не умеет — ничего страшного, Pill закроет её сама через 10 секунд.

### Шаг 2. Упакуйте её в архив

Сложите `.exe` и все нужные файлы в архив `.zip`.

### Шаг 3. Выложите архив на GitHub

1. Создайте на GitHub **публичный** репозиторий для модуля, например `pill-currency`.
2. Справа нажмите **Releases → Create a new release**.
3. В поле **Tag** напишите версию с буквой `v` впереди: `v1.0.0`.
4. Перетащите ваш `.zip` в окно релиза (в поле **Attach binaries**).
5. Нажмите **Publish release**.

Pill всегда берёт **последний** релиз. Версию она узнаёт из тега.

### Шаг 4. Добавьте значок и картинки (по желанию)

Положите в свой репозиторий квадратную картинку `icon.png` (от 128×128) и, если хотите, снимки модуля.
Ссылку на файл берите так: откройте файл на GitHub → кнопка **Raw** → скопируйте адрес из строки браузера.
Он будет похож на `https://raw.githubusercontent.com/ваш-ник/pill-currency/main/icon.png`.

### Шаг 5. Напишите блок модуля

Это описание вашего модуля для магазина. Пример:

```json
{
  "id": "currency",
  "name": "Курс валют",
  "kind": "Виджет",
  "about": "Показывает курс доллара и евро.",
  "author": "ваш-ник",
  "repo": "ваш-ник/pill-currency",
  "exe": "Currency.exe",
  "icon": "https://raw.githubusercontent.com/ваш-ник/pill-currency/main/icon.png",
  "features": [
    { "icon": "money", "title": "Доллар и евро", "text": "Курс прямо в пилюле" },
    { "icon": "refresh", "title": "Сам обновляется", "text": "Раз в час или раз в день" }
  ]
}
```

Что значит каждая строчка — в таблице [ниже](#блок-модуля-подробно).

### Шаг 6. Проверьте у себя

1. Скачайте файл [`modules.json`](modules.json) из этого репозитория.
2. Допишите в него свой блок после блока TaskbarPill, через запятую.
3. Закройте Pill (значок в трее → «Выход») и запустите её так:

```
Pill.exe --modules-catalog C:\путь\к\modules.json --open-modules info ваш-id
```

Pill откроет страницу вашего модуля. Проверьте название, значок и кнопку «Установить».

### Шаг 7. Отправьте заявку

1. Откройте файл [`modules.json`](modules.json) в этом репозитории.
2. Нажмите на значок карандаша **Edit this file**. GitHub сам сделает вашу копию.
3. Допишите свой блок после последнего, через запятую.
4. Нажмите **Commit changes → Propose changes → Create pull request**.

### Шаг 8. Дождитесь проверки

Мы посмотрим модуль и примем заявку. После этого модуль появится в магазине у всех пользователей
при следующем запуске Pill.

### Как выпустить обновление

Сделайте новый релиз с тегом побольше, например `v1.1.0`. Заявку отправлять не нужно.
Pill сама увидит новую версию и покажет пользователю кнопку «Обновить».

## Блок модуля подробно

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Короткое имя: маленькие латинские буквы, цифры и `-`. Потом не меняется |
| `name` | да | Название в магазине |
| `kind` | нет | Короткая подпись: «Виджет», «Панель задач» |
| `about` | да | Описание, одно-два предложения |
| `author` | да | Ваш ник на GitHub |
| `repo` | да | Репозиторий с релизами: `ник/репозиторий` |
| `exe` | да | Имя программы внутри архива, латиницей: `Currency.exe` |
| `icon` | нет | Ссылка на квадратную картинку PNG, от 128×128 |
| `features` | да | Плитки «Что умеет» на странице модуля |
| `details` | нет | Свои строки в блоке «Подробно» |
| `on_remove` | нет | Что будет, если модуль выключить или удалить. Без него — «Программа закроется» |
| `shots` | нет | Картинки для страницы модуля |
| `settings` | нет | Настройки, которые Pill нарисует сама |

Для английского интерфейса можно добавить `name_en`, `kind_en`, `about_en`, `on_remove_en`,
а в плитках, строках и настройках — `title_en`, `text_en`, `value_en` и `options_en`.

### Низ страницы модуля

Внизу страницы у всех модулей одинаковые блоки, Pill собирает их из вашего блока:

- **«Что умеет»** — плитки из `features`.
- **«Подробно»** — автор, ваши строки из `details`, строка из `on_remove`, версия и кнопка проверки обновлений.
- **«Страница модуля»** — ссылка на ваш `repo`.

```json
"features": [
  { "icon": "money", "title": "Доллар и евро", "text": "Курс прямо в пилюле" },
  { "icon": "refresh", "title": "Сам обновляется", "text": "Раз в час или раз в день" }
],
"details": [
  { "title": "Откуда курс", "value": "Центробанк" }
],
"on_remove": "Курс пропадёт из пилюли"
```

Значок плитки — одно из слов: `start`, `monitor`, `window`, `game`, `money`, `refresh`, `music`, `clock`,
`calendar`, `bell`, `weather`, `star`, `settings`, `keyboard`, `wifi`, `battery`, `mic`, `camera`, `search`,
`folder`, `note`, `lock`, `bolt`, `eye`. Без значка будет звёздочка.

Плиток лучше делать чётное число: они стоят по две в ряд.

### Картинки

```json
"shots": [
  { "title": "Виджет", "image": "https://raw.githubusercontent.com/…/shot1.png", "text": "Курс прямо в пилюле." }
]
```

### Настройки

Pill сама нарисует переключатели и кнопки выбора:

```json
"settings": [
  { "key": "ShowEuro", "title": "Показывать евро", "type": "switch", "default": true },
  { "key": "Refresh", "title": "Обновлять", "type": "choice", "options": ["Раз в час", "Раз в день"], "default": 0 }
]
```

- `switch` — переключатель, значение `true` или `false`.
- `choice` — один вариант из нескольких, значение — номер варианта с нуля.

Что выбрал пользователь, Pill записывает в файл `settings.json` рядом с вашим `.exe`:

```json
{ "ShowEuro": true, "Refresh": 0 }
```

Читайте этот файл при запуске. Чтобы настройки менялись сразу, следите за файлом (например, `FileSystemWatcher` в C#).

## Как модуль живёт рядом с Pill

- **Папка.** Pill ставит модуль в `%AppData%\DynamicIsland\modules\<id>\`.
- **Запуск.** Включённый модуль Pill запускает при своём старте и по переключателю.
- **Выключение.** Pill запускает `ваш.exe --exit` и ждёт 10 секунд. Не закрылся — Pill закрывает его сама.
- **Удаление.** Pill выключает модуль и стирает его папку.

## Правила

- Никакой рекламы, сбора данных и скрытых действий.
- Модуль, нарушивший правила, убирается из списка.
