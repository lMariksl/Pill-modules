# Модули для Pill

Здесь лежит список модулей, который Pill показывает в разделе «Управление → Модули → Доступные модули».
Pill скачивает файл [`modules.json`](modules.json) каждый раз, когда открывается магазин.
Добавили модуль в этот файл — он появился в магазине у всех.

## Что такое модуль

Обычная программа для Windows (на любом языке), которую Pill скачивает, запускает и выключает.
Если модуль упадёт, Pill продолжит работать.

## Как добавить свой модуль

1. Выложите программу в релиз на GitHub в своём репозитории: архив `.zip`, внутри exe и всё, что ему нужно.
   Pill берёт **последний** релиз, версия — из тега (`v1.2.0`).
2. Пришлите заявку (pull request), которая добавляет ваш блок в `modules.json`.
3. После проверки модуль появится в магазине.

## Блок модуля

```json
{
  "id": "currency",
  "name": "Курс валют",
  "kind": "Виджет",
  "about": "Показывает курс доллара и евро.",
  "author": "vasya",
  "repo": "vasya/pill-currency",
  "exe": "Currency.exe",
  "icon": "https://raw.githubusercontent.com/vasya/pill-currency/main/icon.png",
  "shots": [
    { "title": "Виджет", "image": "https://raw.githubusercontent.com/vasya/pill-currency/main/shot1.png", "text": "Курс прямо в пилюле." }
  ],
  "settings": [
    { "key": "ShowEuro", "title": "Показывать евро", "type": "switch", "default": true },
    { "key": "Refresh", "title": "Обновлять", "type": "choice", "options": ["Раз в час", "Раз в день"], "default": 0 }
  ]
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Латиница, цифры и `-`. Имя папки модуля, не меняется |
| `name` | да | Название в магазине |
| `kind` | нет | Короткая подпись: «Виджет», «Панель задач» |
| `about` | да | Описание, одно-два предложения |
| `author` | да | Ваш ник на GitHub |
| `repo` | да | Репозиторий с релизами: `ник/репозиторий` |
| `exe` | да | Имя программы внутри архива |
| `icon` | нет | Квадратная картинка PNG, от 128×128 |
| `shots` | нет | Картинки для страницы модуля: название, ссылка, подпись |
| `settings` | нет | Настройки, которые Pill нарисует сама |

Для английского интерфейса можно добавить `name_en`, `kind_en`, `about_en`, а в настройках `title_en` и `options_en`.

## Как модуль живёт рядом с Pill

- **Папка.** Pill ставит модуль в `%AppData%\DynamicIsland\modules\<id>\`.
- **Запуск.** Включённый модуль Pill запускает при своём старте и по переключателю.
- **Выключение.** Pill запускает `ваш.exe --exit` и ждёт 10 секунд. Не закрылся — процесс снимается.
- **Настройки.** Pill пишет выбор пользователя в `settings.json` в папке модуля, ключи — из `settings`.
  Следите за файлом (например, `FileSystemWatcher`) и применяйте изменения сразу.

## Правила

- Никакой рекламы, сбора данных и скрытых действий.
- Исходный код должен быть открыт.
- Модуль, нарушивший правила, убирается из списка.

## Проверить свой блок до заявки

Сохраните `modules.json` со своим блоком у себя и запустите Pill так:

```
Pill.exe --modules-catalog C:\путь\modules.json --open-modules info ваш-id
```
